# Projet_A3P

# Description

Ce projet vise à explorer différentes techniques d’anonymisation et à identifier les attaques potentielles sur des jeux de données spécifiques. Il s’inscrit dans le cadre d’une compétition organisée via Codabench et utilise le framework Snakemake pour la génération des tâches.

# Technologies utilisées

 Python : Langage principal du projet.

Snakemake : Utilisé pour la génération et la gestion des tâches.

Codabench : Plateforme utilisée pour gérer la compétition et l’évaluation des résultats.

Git : Gestion du code source et des documents associés.

# Objectifs du projet

Sélectionner et implémenter des techniques d’anonymisation.

Identifier des attaques connues et les modéliser.

Préparer et traiter un ou plusieurs jeux de données pertinents.

Définir et structurer une séquence d’attaques sous forme de capture the flag (gamification).

Implémenter un Snakemake reproductible pour la génération des tâches.

Configurer l’interface et les phases de la compétition sur Codabench.

# Organisation

Méthodologie Agile : Suivi du projet avec des démonstrations fréquentes.

Communication : Échanges via email.

Dépôt Git : Centralisation du code, des documents et des comptes-rendus de réunions.
